# Sea Cloud Consulting site

The canonical site is the multi-page build on the `multipage-rebuild` branch.
GitHub Pages publishes the repository root from that branch to:

https://mikeblakeduncan.github.io/SeaCloudConsultingSite/

Before editing or previewing the site, confirm the working tree is on the
GitHub Pages source branch and compare the relevant page with the live URL.
The `main` branch contains a legacy single-page build and is not the source of
the published site.
